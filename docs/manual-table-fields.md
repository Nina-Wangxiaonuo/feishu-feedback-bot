# 飞书分析表手动字段清单

仅在应用无权通过 API 修改字段时使用。字段名称必须完全一致。

## AI-每日反馈粗表

将默认主字段“文本”重命名为“分析记录 ID”，然后添加：

| 字段名 | 类型 |
|---|---|
| 原始记录 ID | 文本 |
| 反馈日期 | 日期 |
| 反馈时间 | 日期 |
| 反馈人员 | 文本 |
| 原始反馈 | 文本 |
| 操作系统 | 文本 |
| 有效反馈 | 复选框 |
| 反馈类型 | 文本 |
| 所属模块 | 文本 |
| 规范标题 | 文本 |
| 问题摘要 | 文本 |
| 用户目标 | 文本 |
| 预期结果 | 文本 |
| 实际结果 | 文本 |
| 关键词 | 文本 |
| 严重程度 | 文本 |
| AI 置信度 | 数字 |
| 信息完整度 | 文本 |
| 聚合问题 ID | 文本 |
| 分析版本 | 文本 |
| 分析时间 | 日期 |
